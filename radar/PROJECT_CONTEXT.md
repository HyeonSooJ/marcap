## 주제 선정 과정 (탈락한 후보들과 이유)

1. **레버리지/신용융자 리스크 조기경보** — 기각. "위험하다"는 결론 자체가 관리종목
   지정, 신용등급, 증권사 위험고지 등으로 이미 시장에 흔한 정보라 창의성 부족 판단.
2. **바이오텍 임상시험 성공확률 예측** — 기각. 작년 KB AI 챌린지 대상작과 핵심
   메커니즘(임상 성공/실패 예측 → 투자 리스크 관리)이 동일해서 "베낀 것" 인상 위험.
3. **코스닥 종목 추천 AI** — 기각. 무인가 투자자문 규제 리스크 + 기존 로보어드바이저와
   차별성 없음.
4. **2,30대 자산격차 진단 서비스** — 보류. 본인이 직접 취재한 인터뷰(코스피 상승
   수혜자 vs 비수혜자, 20대 자산격차)에서 출발한 아이디어라 스토리텔링은 강하지만,
   최종적으로 아래 5번 방향과 통합 논의 중 후순위로 밀림. 필요시 재검토 가능.

## 최종 채택 주제

### 핵심: "밈스탁 버블 확산 조기경보" (SIR 역학모델 기반)

**문제 정의**: 최근 코스닥 급락과 레버리지發 반대매매 이슈로 개인투자자 피해가
부각됨. 기존 위험 경고 서비스들은 재무비율/신용지표 등 "누구나 보는 지표"로
결론("위험하다")을 내리는데, 이는 이미 포화된 접근.

**차별화 아이디어**: 감염병이 사람 사이에 퍼지듯 특정 종목에 대한 "관심"도
커뮤니티/뉴스/검색을 통해 확산된다는 관점에서, SIR(Susceptible-Infected-Recovered)
역학모델을 종목의 관심 확산에 적용. 지금 이 종목이 확산곡선의 어느 단계
(초기 확산기 / 포화기 / 정점 통과 후 하락기)에 있는지 진단.

- 재무/신용 지표가 아니라 "정보 확산의 속도와 패턴"이라는 완전히 다른 축으로
  버블을 진단하는 것이 핵심 차별점
- 개발자(본인)의 생명공학 전공 배경을 컨셉이 아니라 실제 정량 모델(SIR)로
  녹여내는 것이 기술적 진정성/차별성의 핵심 근거

**데이터 소스**:
- marcap: 일별 시가총액 / 거래대금 / 등락률 (감염 규모 프록시)
- 네이버 종목토론방 게시글 수 (관심 확산 프록시, 비공식 크롤링 필요 — 실현가능성 검증 필요)
- 뉴스 언급량 (기존 radar/src의 news_collector.py 재활용)
- 네이버 데이터랩 검색량 API (확산 속도 프록시 — 셋업 필요)

**개인화 레이어 (A-lite, 부가 기능)**: 전체 매매이력 반사실 시뮬레이터 같은
무거운 기능 대신, 간단한 온보딩 설문으로 투자 성향(물타기형/추격매수형/
장기보유형)을 태깅 → 확산 단계 진단과 결합해 "당신 성향상 지금 이 종목은
특히 위험하다"는 개인화 경고 메시지 생성.

**기존 마캡레이더 인프라 재사용 계획** (완전 재시작 아님):
- marcap 데이터 파이프라인 → 그대로 재사용
- radar/src의 DART 공시 수집기, 네이버 뉴스 수집기 → 그대로 재사용
- LLM 원인 해설 리포트 생성기 → 확산 단계 설명으로 확장
- radar/app.py (Streamlit 대시보드) → 확산 단계 시각화로 확장
- 백테스트 프레임워크(관리종목 지정 이력 대비 리드타임 측정 방식) → 과거
  밈주식/버블 사례 검증으로 확장
- 새로 만들어야 하는 것: 종목토론방 크롤러, 검색량 API 연동, SIR 모델 피팅 로직,
  투자성향 태깅 로직
